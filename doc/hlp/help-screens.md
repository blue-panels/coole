# Query boxes <a id="querybox"></a>

In a query box, use the arrow keys or the highlighted letter of a button to choose it, and Enter to press it; a click with the mouse on a button presses it as well. Esc closes the box without an answer.

# How to use help <a id="how-to-use-help"></a>
<a id="help"></a>

You can use the cursor keys or the mouse to move around in the help window. Press **down arrow** to move to the next link or to scroll down. Press **up arrow** to move to the previous link or to scroll up. Press **right arrow** or **Enter** to follow the current link. Press **left arrow** to go back in the history of the nodes you have visited.

If your terminal doesn't support the cursor keys, use the **space bar** to scroll forward and the **b** key to scroll back. The **Tab** key moves to the next link, and **Enter** follows it. The **l** key goes back in the history of the nodes you have visited. Press **Esc** to leave the help.

The left mouse button follows a link or scrolls. The right mouse button goes back in the history of the nodes.

The full list of the keys of the help window:

[General movement keys](#general-movement-keys) are accepted.

```
Tab             move to the next link
Alt-Tab         move to the previous link
Down            next link, or scroll a line down
Up              previous link, or scroll a line up
Right, Enter    follow the current link
Left, l, F3     back in the history of visited nodes
F1              show this help on the help
n               go to the next node
p               go to the previous node
c, F2           go to the contents
F10, Esc        leave the help
```
